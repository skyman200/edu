## 고친 뒤 반영

`index.html`을 고치면 두 곳 모두 올립니다.

- GitHub Pages: `git push` (main)
- Cloudflare Pages: `index.html`만 든 폴더를 `npx wrangler pages deploy <폴더> --project-name kimcook-edu --branch main`
